# Phase 5 Wallpaper Pack Provenance

## Secret Aero Nostalgia

- Pack id: `secret-aero-nostalgia`
- Implementation: `environment/nostalgicWallpaperPack.ts`
- Assets: `assets/wallpapers/aero-*.svg`
- Creator/source: original vector artwork created in this repository
- External images, characters, brands, or compositions: none
- Runtime dependencies: none; every wallpaper is bundled and works offline
- Missing-asset behavior: every SVG background is layered over a deterministic
  CSS gradient fallback

The pack contains Hillside Companion (the first-run default), Coastal Morning,
Lagoon Night, Rain Garden, and Sunlit Study Room. All scenes use a fixed
1600×1000 view box with the quieter detail area on the left for desktop-icon
readability and cover framing in both Classic 4:3 and Native Display modes.
