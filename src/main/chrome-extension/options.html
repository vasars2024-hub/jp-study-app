AI OCR / Dictionary AI

Choose what a highlight and an OCR each resolve to. AI OCR annotates the whole sentence — grammar, vocabulary, level, formality and nuance — and lets you card it or snapshot it into the notebook. Dictionary AI keeps the instant offline lookup. The two gestures are set separately.

Shorter selections stay on the offline dictionary — a one-word cloud call is slower and costs money for an answer the dictionary already has.

What the analysis contains, which deck cards go to, and automatic notebook snapshots are set in Gum → Settings → Study → AI analysis. An API key is required (Flashcards → AI Card Studio).

Radial wheel

A quick action ring opened with Alt+Shift+W. One command per position; the center always cancels.

Each command can be assigned once — picking a command that is already placed swaps the two positions. Commands that don't apply to the current page (like Download video outside YouTube) appear disabled on the wheel. Keyboard: 1–6 run a position, arrows move the highlight, Esc cancels.
