# Noctis UI

The Study OS workspace — human-facing Fluent panels inside civilization windows.

UI is separate from `rendering/`. UI hosts readable workspace chrome; rendering hosts the living diorama.

Canon: `docs/GAME_DESIGN.md`, `docs/UI_DESIGN.md`

## Subfolders

| Folder | Role |
|--------|------|
| `panels/` | Civilization inspection and status panels |
| `dashboard/` | Summary dashboards and overview layouts |
| `widgets/` | Compact embedded workspace widgets |

The Study OS keeps normal readable text. Diegetic Noctae tools stay non-visual per the ecological engine doc.
