# User intent

Study Mode must become the connective learning workflow for the media library,
player, subtitles, known vocabulary, imported JLPT lists, flashcards, Anki, and
AI Mode.

The first shippable slice is:

```text
Favorite / Study Queue
→ readiness analysis
→ reversible vocabulary filtering
→ card preview
→ internal deck or Anki
→ exact return to media
```

Required qualities:

- Use real application data and explain every recommendation.
- Repair shared dependencies before Study Mode consumes them.
- Keep deterministic behavior available without AI.
- Make AI use typed, auditable operations.
- Preserve exact media, subtitle, sentence, and timestamp context.
- Provide preview, confirmation, retry, and undo where appropriate.
- Use a minimal Fluent dark/deep-red workspace with purposeful real-state motion.
- Do not use decorative emoji, fake progress, fake statistics, or dead controls.
- Keep work resumable without relying on chat history.
